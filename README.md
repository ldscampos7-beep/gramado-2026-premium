## Como atualizar
1. Abra o repositório `gramado-2026-premium`.
2. Add file > Upload files.
3. Envie `app.py`, `requirements.txt` e `README.md`.
4. Confirme a substituição e clique em Commit changes.
5. O Streamlit atualiza automaticamente.
