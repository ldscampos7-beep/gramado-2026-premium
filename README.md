
# Gramado 2026 — Premium

Versão visual premium do app pessoal da viagem.

## O que tem
- dashboard “Hoje”
- roteiro por dia
- check-ins
- gastronomia com favoritos
- Cara de Mau
- controle do YUO
- registro e exclusão de gastos
- backup/restauração
- dicas de economia
- look do dia

## Publicar gratuitamente
1. Crie um repositório no GitHub chamado `gramado-2026-premium`.
2. Envie `app.py` e `requirements.txt`.
3. Acesse https://share.streamlit.io/
4. Faça login com GitHub.
5. Clique em **Create app**.
6. Escolha seu repositório.
7. Em **Main file path**, escolha `app.py`.
8. Clique em **Deploy**.

## No celular
Abra o link `.streamlit.app` e use **Adicionar à Tela de Início**.

## Backup
O Streamlit pode reiniciar sessões. Use o botão **Backup da viagem** na barra lateral ao fim de cada dia.
